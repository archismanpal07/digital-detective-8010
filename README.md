## Topics explored

IPOS, hardware and software, command-line navigation, safe file operations, processes and permissions, Python execution, binary and hexadecimal conversion, text encoding, version control, branches and Pull Requests, DNS, routers, and client-server communication.

## Run the number converter

From the repository root, run `python3 mission-05-numbers-data/number_converter.py` and enter a positive decimal integer. The program prints its binary and hexadecimal forms.

## Learning summary

This project connects everyday computer use to the systems underneath it. Small, reversible Terminal exercises show how files and processes are managed; the Python exercises show how number representations can be checked; and Git provides a history of the work.

Each mission is documented and committed separately. Personal account, device, and network identifiers are omitted from the public notes.
