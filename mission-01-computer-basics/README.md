# Mission 1 - Know your computer

## 1. Task / objective
Trace an everyday activity through input, processing, output, and storage; classify hardware and software; and identify computer systems used outside a laptop or phone.

## 2. Work completed

### Task 1.1: IPOS - typing and saving a document

| Stage | What happens | Hardware / component |
|---|---|---|
| Input | I type words and choose Save. | Keyboard and trackpad |
| Processing | The operating system and editor process the keystrokes and prepare the document data. | CPU and memory |
| Output | The text and save confirmation appear on screen. | Display |
| Storage | The saved document is written as a file so it remains available later. | SSD |

### Task 1.2: Hardware and software

| Item | Hardware or software? | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Enters letters and commands. |
| Trackpad | Hardware | Not applicable | Moves the pointer and selects controls. |
| Display | Hardware | Not applicable | Shows the operating system and app output. |
| SSD | Hardware | Not applicable | Stores files and installed software. |
| macOS | Software | Operating system | Manages devices, files, memory, and applications. |
| Google Chrome | Software | Application | Opens websites and web apps. |
| Terminal | Software | Application | Runs command-line tools and programs. |
| Homebrew | Software | Utility / package manager | Lists and manages installed software packages. |

### Task 1.3: Computer systems around you

| System | Main purpose | One input | One output |
|---|---|---|---|
| ATM | Provides cash and banking operations. | Bank card | Cash or a receipt |
| Traffic signal | Directs traffic through an intersection. | Timer or vehicle sensor | Red, amber, or green light |
| Ticket machine | Sells a ticket or transit pass. | Destination selection | Printed or digital ticket |

## 3. Commands / tools used
- Text editor and Markdown - recorded the tables.
- No Terminal command was needed for these examples.

## 4. My understanding
A computer receives input, processes it, gives feedback, and can save the result. Hardware is the physical equipment; software gives the computer instructions. The same pattern appears in devices such as ATMs and traffic signals.
